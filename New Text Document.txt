==================================================
PROJECT CONCEPT
==================================================

The project is an NLP-based tourism communication system supporting four directions:

1. English → Malayalam
2. Malayalam → English
3. Manglish → English
4. English → Manglish

Definition:

Manglish means Malayalam written using English/Roman characters.

Example:

English:
"I need a taxi."

Malayalam:
"എനിക്ക് ഒരു ടാക്സി വേണം."

Manglish:
"Enikku oru taxi venam."

The application should be focused on tourist communication in Kerala.

Tourism categories include:

- Hotel / Accommodation
- Food / Restaurant
- Transportation
- Directions
- Shopping
- Sightseeing
- Emergency
- General Conversation
